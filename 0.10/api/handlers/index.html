    Handlers¶

    A handler acquires a dataset published as files, stores the files, and loads them for a source. Construct the handler, then call load_data, load_into_dataframe, or the method named below. The shared machinery is documented in the handler base, not on these pages.

    from gigaspatial import GHSLDataHandler, WPPopulationHandler
from gigaspatial.handlers import GHSLDataConfig, GHSLDataDownloader, GHSLDataReader

    Every handler is importable from gigaspatial. Its config, downloader, and reader are in gigaspatial.handlers. A handler takes its config fields as keyword arguments, so most scripts only need the handler.

    GHSL¶

    Bases: BaseHandler

    Handler for GHSL (Global Human Settlement Layer) dataset.

    This class provides a unified interface for downloading and loading GHSL data. It manages the lifecycle of configuration, downloading, and reading components.

    		 False
    **kwargs

    		 {}

    Type Description

    bool

    bool

    Raises:

    Type Description

    Exception

    Google and Microsoft buildings¶

    Bases: BaseHandler

    Handler for Google-Microsoft Combined Buildings Dataset.

    Provides end-to-end workflow for downloading, caching, and reading merged Google V3 Open Buildings and Microsoft Global Building Footprints.

    Features: - Cloud-native GeoParquet streaming - Automatic partition discovery by geometry - Source filtering (Google/Microsoft) - Confidence score filtering - Local caching for repeated access

    Example

    config = GoogleMSBuildingsConfig() handler = GoogleMSBuildingsHandler(config) geometry = Polygon([...]) # Your area of interest buildings = handler.load_data(geometry)
